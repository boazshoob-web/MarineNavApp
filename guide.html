1. Overview

Marine Nav Assist provides real-time wind, wave, and pressure conditions along the Israeli Mediterranean coastline. It covers 17 coastal stations from Rosh HaNikra in the north to Ashkelon in the south.

The app runs entirely in your browser — no account or backend required. All data comes from free public APIs (Open-Meteo for weather, EMODnet for bathymetry).

Quick Start

  1. Open the app — the map loads centered on the Israeli coast.
  2. Weather data auto-fetches for all 17 stations (wind arrows and wave badges appear).
  3. Tap any wind arrow to see detailed wind, wave, and swell data.
  4. Use the floating menu buttons (left edge) to open panels: Weather, Route, Tracking, Anchor, Logbook.

2. Map & Layers

Base Maps

Use the layer control (bottom-right) to switch between:

  • Standard Map — CartoDB Positron (default, clean style)
  • Sea Depth (EMODnet) — EU bathymetry tiles
  • Sea Depth (GEBCO) — global bathymetry tiles

Overlay Layers

Toggle these independently:

  • Wind Arrows — colored arrows showing wind direction and speed at each station
  • Wave Heights — colored badges showing wave height west of each station
  • Isobars / Isobar Labels — atmospheric pressure contour lines
  • Depth Contours / Depth Labels — sea floor depth lines
  • AI Wave Estimate — Gemini Vision wave analysis badges
  • Route — your planned route
  • My Location — GPS position marker
  • Track — recorded GPS breadcrumb trail
  • Legend — color scale reference

Map Controls

  • Search (top-right) — search for a place name to pan the map
  • Locate (top-left, crosshair icon) — center map on your GPS position
  • Zoom — pinch on touch, scroll wheel on desktop, or +/- buttons

3. Weather Stations

17 stations along the coast display real-time forecasts:

Rosh HaNikra • Nahariya • Akko • Haifa • Atlit • Dor • Caesarea • Hadera • Netanya • Herzliya • Tel Aviv • Jaffa • Bat Yam • Rishon LeZion • Palmachim • Ashdod • Ashkelon

What You See on the Map

  • Wind arrows — colored by speed, pointing in the wind direction
  • Speed label — wind speed in knots below each arrow
  • Wave badge — colored box showing wave height (m), offset seaward

Station Popup

Tap a wind arrow to see:

  • Wind — speed (kts), compass direction, gusts
  • Pressure — barometric pressure (hPa)
  • Waves — height (m), direction, period (s)
  • Swell — height, direction, period (if present)
  • AI Wave Estimate — if Gemini API key is configured
  • Webcam links — for stations with cameras

Auto-Refresh

Open the Wind & Waves panel to configure:

  • Refresh interval — default 5 minutes
  • Refresh Now — force immediate update
  • Pause — temporarily stop auto-refresh

4. Isobars

Isobars show atmospheric pressure patterns across the region. Enable the Isobars layer to display them.

  • Thick lines — every 4 hPa
  • Thin lines — every 1 hPa
  • Labels — enable Isobar Labels to show pressure values

Isobars are computed from a 12×12 pressure grid covering the eastern Mediterranean (30.5°N–34.0°N, 33.0°E–37.0°E).

5. Webcams & AI Wave Estimate

Viewing Webcams

  1. Tap a wind arrow at a station with cameras.
  2. In the popup, look for webcam links (e.g., "Bat Galim", "Surf Club").
  3. Tap a link to open the live feed in a modal.
  4. Close with the X button or tap outside.

AI Wave Estimate

Uses Google Gemini Vision to analyze webcam images and estimate wave conditions.

  1. Open the Wind & Waves panel.
  2. Enter your Gemini API key in the "Gemini API Key" field.
  3. The app will analyze available webcam images automatically.
  4. Results appear in station popups as estimated wave height with confidence level.
AI estimates supplement — not replace — official forecast data. Confidence varies by lighting and camera quality.

6. Depth Contours

Enable the Depth Contours layer to see sea floor depth lines on the map.

  • Contours load dynamically as you pan and zoom.
  • Enable Depth Labels to see depth values in meters.
  • Data source: EMODnet high-resolution bathymetry.

For visual depth shading, switch to the Sea Depth (EMODnet) or Sea Depth (GEBCO) base map.

Drawing a Route

  1. Tap Draw Route — button turns orange.
  2. Tap the map to place waypoints (up to 50).
  3. Waypoints connect with a blue line showing distances.
  4. Tap Stop Drawing to finish.

Route Controls

Clear
Remove all waypoints and start fresh.
Auto-Correct Route
Smooth the path and check depth clearance. Flags shallow segments.
Show Hazards
Display hazard circles at segments shallower than your draft + safety margin.
Export GPX
Download route as a GPX file.
Import GPX
Load a route from a GPX file.
Save Route
Save to device storage (IndexedDB) for later use.
Save for Offline
Download map tiles along the route for offline navigation.

Depth Hazards

When Check depth clearance is enabled, Auto-Correct identifies segments where the sea floor is shallower than your required clearance (draft + safety margin). Hazard circles appear on the map — tap one to see the depth vs. your vessel requirements.

Saved Routes

Saved routes appear below the route controls. Each shows:

  • Route name (tap to load)
  • Storage size and age
  • Share button — export as GPX
  • Delete button

8. Tracking

Records your GPS position as you move, drawing a breadcrumb trail on the map.

Recording a Track

  1. Open the Tracking panel.
  2. Optionally enter a track name.
  3. Tap Start — GPS tracking begins, green trail appears on map.
  4. Tap Mark Position to drop a numbered pin at your current location.
  5. Tap Stop to pause recording.

Track Controls

Clear
Erase all track points and pins.
Export GPX
Download track as a GPX file (includes pins as waypoints).
Import GPX
Load a previously exported track or route from a GPX file.
Save as Route
Convert the track to a route (simplified with 50m tolerance) and save to device storage.

9. Lead Line & Sweep Lines

Lead Line

A dashed blue line extending ahead of your boat in the direction you're heading.

  • Set the length (0–500 nm) in the Lead line field in the Tracking panel.
  • Set to 0 to hide it.
  • Updates in real-time as your heading changes.

Sweep Lines

Automatically shown when the lead line is active and you have a valid heading. They display your heading range over the last 15 minutes:

LineColorMeaning
Left extremeRedFarthest counter-clockwise heading
Right extremeGreenFarthest clockwise heading
AverageBlackDistance-weighted average heading
The average (black) line weights headings by distance covered, so directions where you made good speed contribute more than slow drifting.

10. Anchor Watch

Monitors your position and alerts you if you drift beyond a set radius from your anchor point.

Setting the Anchor

  1. Open the Anchor Watch panel.
  2. Set the alert radius (5–500 m, default 30 m).
  3. Tap Drop Anchor — uses your current GPS position.
  4. An anchor marker and radius circle appear on the map.

Monitoring

  • Green status — within safe radius, showing current distance.
  • Red / DRIFT ALARM — you've exceeded the radius. Beep and vibration alert.

Tap Clear to remove the anchor and stop monitoring.

iOS Safari does not support vibration. The audible beep alarm will still work if audio has been enabled by a prior tap.

11. Digital Logbook

A traditional maritime logbook in digital form. Records voyage details and periodic entries with navigation, engine, and weather data.

Starting a New Log

  1. Open the Logbook panel.
  2. Tap New Log.
  3. Enter captain name and departure details.
  4. The first entry form opens automatically.

Adding Entries

Tap Add Entry to record a log entry. Fields include:

  • Navigation: Date, Time, Position, SOG, COG (auto-filled from GPS)
  • Engine: RPM, Temperature (manual)
  • Weather: Wind Speed, Wind Dir, Sea State, Pressure, Visibility, Weather conditions
  • Comments: Free text
When WX Here is active, wind speed, wind direction, and barometric pressure auto-fill and are marked "AUTO". You can still override them manually.

Closing a Log

Tap Close Log when the voyage is complete. You'll be prompted for the arrival location. Closed logs move to the Saved Logs list.

Exporting

Tap Export (active log) or the share button on a saved log to download/share as CSV. The CSV includes all entries with full headers, compatible with Excel.

Saved Logs

Listed below the active log controls. Each shows date, captain name, entry count, and status (open/closed). Tap to view or export; use the share or delete buttons.

12. GPS & SOG/COG Display

When GPS is active, the top center of the screen shows:

  • SOG — Speed Over Ground in knots
  • COG — Course Over Ground in degrees + compass direction

Your position appears on the map as:

  • Moving: Blue arrow pointing in your heading direction
  • Stationary: Blue circle dot
  • Accuracy circle: Light blue circle showing GPS precision

Tap the locate button (crosshair icon, top-left) to center the map on your position.

GPS requires location permission from your browser/device. HTTPS is required for geolocation on most browsers.

13. Weather at Location (WX Here)

Shows weather conditions at your exact GPS position (not just the nearest station).

  1. The WX toggle appears near the SOG/COG display when GPS is active.
  2. Enable it to fetch wind, wave, and temperature data for your location.
  3. Data auto-refreshes as you move (cached for 10 min or 5 km).

Displayed values:

  • W — Wind speed (kts)
  • Wv — Wave height (m)
  • Temp — Air temperature (°C)

When active, these values auto-populate logbook entries (marked "AUTO").

14. Offline Use

Marine Nav Assist works offline as a Progressive Web App (PWA). Weather data and map tiles can be cached for use without internet.

Installing as PWA

  • iOS Safari: Tap Share → Add to Home Screen
  • Android Chrome: Tap menu → Install App / Add to Home Screen
  • Android APK: Install the APK directly

Downloading Map Tiles

  1. Pan and zoom the map to the area you want.
  2. Tap the download icon (bottom-left of map).
  3. Set zoom range (default 8–15). Higher zoom = more detail, more storage.
  4. Tap Download — progress bar shows completion.
  5. Downloaded tiles are cached for offline viewing.

Saved Routes

Routes saved via Save Route persist in device storage (IndexedDB) and can be loaded offline. Use Save for Offline to also download map tiles covering the route area.

Saved Logs

All logbook data is stored locally in IndexedDB and available offline.

Export Formats

Import

  • Import route GPX: Import GPX button in Route Planning panel. Accepts both route (<rte>) and track (<trk>) formats.
  • Import track GPX: Import GPX button in Tracking panel. Loads track points and waypoint pins.

Sharing on Mobile

On mobile devices, export buttons open the native share sheet (WhatsApp, Email, Files, etc.). On desktop browsers, files are downloaded directly.

16. iOS Notes

  • Vibration: navigator.vibrate() is not supported in Safari. Anchor Watch alarm will beep but not vibrate.
  • Audio: Sound must be unlocked by a tap gesture before alarms can play. Tap any button in the app to enable audio.
  • PWA: Add to Home Screen via Safari's Share menu for the best experience.
